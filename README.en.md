## ✨ What it does

<div align="center">
   
| Feature | What you get |
|---------|--------------|
| 📸 **Smart Camera** | Auto-frames each object - icons always look clean. |

| 📦 **Batch Processing** | Generate icons for many objects at once. |

## 🚀 Installation

<details>
<summary><strong>📦 Via .unitypackage (easiest)</strong></summary>

1. Go to [Releases](https://github.com/NeonShadowYT/IconCreator/releases).
2. Download the `.unitypackage` of the latest release.
3. In Unity: `Assets > Import Package > Custom Package...` → select the file → `Import`.

> Perfect if you want a stable version without Git fuss.

</details>

<details>
<summary><strong>🔗 Via Git URL (for updates)</strong></summary>

1. Open **Package Manager** (`Window > Package Manager`).
2. Click `+` → **"Add package from git URL..."**.
3. Paste: `https://github.com/NeonShadowYT/IconCreator.git`
4. Click **"Add"**.

> This keeps you on the bleeding edge.

</details>

<details>
<summary><strong>📁 Manual (from ZIP)</strong></summary>

1. Download the repo as ZIP (`Code > Download ZIP`).
2. Unzip it.
3. Drag the `Assets` folder into your project.
4. Restart Unity.

> Be careful not to overwrite your own files with the same names.

</details>

### 🎯 Objects
- Drag prefabs, scene objects, or folders with prefabs into the list.
- The tool checks for visible meshes automatically.
- Invalid objects are ignored.

### ⚙️ Icon Settings
- **Save folder** - where icons will be saved.
- **Size** - from 32 to 2048 px.
- **Padding** - space between object edge and the frame.
- **Camera rotation** - tilt it however you like.
- **Scene shadows** - toggle real-time shadow rendering.

#### Directional Light
- Rotation, color, intensity - all under your control.

#### Point Light
- Up to 2 sources.
- Each with its own position, color, and intensity.

### 👥 Custom Shadow
- **Enable/Disable** - turn it on when needed.
- **Color** - includes alpha for transparency.
- **Offset** - move the shadow along X and Y.
- **Scale** - make it smaller or larger than the object.

### 🖌️ Texture
- **Compression** - `CompressedHQ`, `Compressed`, `Uncompressed`.
- **Filter** - `Point`, `Bilinear`, `Trilinear`.
- **Aniso Level** - from 0 to 16.

### 🏷️ Tags & Layers
- **Camera Tag** - pick from existing tags.
- **Objects Layer** - layer used for rendering objects.

> [!IMPORTANT]
> I recommend using `EditorOnly` for the camera and `TransparentFX` for objects - fewer conflicts.

This is a game-changer. You can save any setup as a preset, then apply it instantly.

1. Tweak everything the way you want.
2. Type a preset name and hit **"Save"**.
3. The preset appears in the list with a thumbnail.
4. To apply - just click **"Load"** on the preset you need.
5. Delete a preset with the **"Delete"** button.

Everything is stored as JSON files in the `Presets` folder. Share them between projects if you want.

## 👁️ Live Preview

Add objects, tweak settings - the preview updates automatically.  
If you have many objects, the preview grid scrolls smoothly.

## ⚡ Quick Start

1. **Open** `Neon Imperium > Создатель иконок` at the top of Unity.
2. **Drop** your prefabs into the object list.
3. **Tweak** settings (512px, 10% padding is a good start).
4. **Check** the live preview.
5. **Hit** «Создать иконки» (Create Icons).

Done!

## 🛠️ Performance Tips

- For **UI icons** - use 128–256px, turn off shadows.
- For **store previews** - 1024px, high-quality compression.
- For **batch generation** - disable shadows, use `Compressed`.
- For **premium quality** - enable shadows, use `CompressedHQ` and `Trilinear`.

## 🐛 Troubleshooting

<details>
<summary><strong>🖤 Icons save with a black background</strong></summary>

**Why:** Likely misconfigured layers or camera settings.

**Fix:** Make sure the camera has the `EditorOnly` tag and objects are on the `TransparentFX` layer. Also check `RenderShadows` and camera settings in the «Настройки иконки» section.

</details>

<details>
<summary><strong>👻 Object is invisible</strong></summary>

**Why:** Likely misconfigured layers or camera settings.

**Fix:** Make sure the camera has the `EditorOnly` tag and objects are on the `TransparentFX` layer. If that doesn't help - check your URP Render Data `Filtering` section and camera settings in the «Настройки иконки» section.

</details>

<details>
<summary><strong>⛔ Tool doesn't work in Play Mode</strong></summary>

**Why:** Designed that way to avoid scene conflicts during gameplay.

**Fix:** Just exit Play Mode - everything will work again.

</details>
